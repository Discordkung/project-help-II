# DSEE Buddy — แชทผู้ช่วยหลักสูตร DSEE (ใช้ได้ทั้งคอมและมือถือ)

```
dsee_chat/
├─ backend/
│  ├─ server.py        ← เซิร์ฟเวอร์ Flask (API แชท + อัปโหลดไฟล์ + ประวัติแชท)
│  ├─ dsee_core.py     ← สมองของแชท: เลือกวิธีตอบให้แม่นที่สุด (rule → RAG+โมเดล → ทั่วไป)
│  ├─ db.py            ← ฐานข้อมูล SQLite เก็บประวัติแชท (แยกตามเครื่อง ไม่ต้องล็อกอิน)
│  └─ rag_index.json   ← ข้อมูลหลักสูตร DSEE 2566 ที่ใช้ตอน "ตอบจริง" (ห้ามลบ)
├─ frontend/
│  ├─ index.html       ← หน้าแชท (รองรับมือถือ + โหมดมืด + ลิ้นชักประวัติแชท)
│  ├─ style.css
│  └─ app.js
├─ dataset/             ← ชุดสร้าง dataset สำหรับ "เทรนโมเดลใหม่" (ใช้คู่กับ Colab เท่านั้น)
│  ├─ dsee_kb.py        ← ข้อมูลหลักสูตรดิบ (ต้นทางเดียวกับ rag_index.json ด้านบน)
│  ├─ make_dataset.py   ← สร้าง dataset.jsonl + rag_index.json จาก dsee_kb.py
│  ├─ dataset.jsonl     ← ชุดข้อมูลเทรนล่าสุด (2,634 บทสนทนา จาก Colab)
│  ├─ rag_index.json    ← สำเนาเดียวกับ backend/rag_index.json (เช็กแล้วตรงกัน)
│  └─ test50.py         ← ชุดคำถามทดสอบ 50 ข้อที่ใช้ตรวจความแม่นยำบน Colab (ผลล่าสุด 50/50)
├─ training/            ← (ใหม่) เทรนโมเดลในเครื่องเอง แทน Colab ได้ ถ้ามีการ์ดจอ NVIDIA — ดู training/README.md
│  ├─ config.py         ← ตั้งค่าการเทรน (เทียบเท่าเซลล์ #@param บน Colab)
│  ├─ 02_train.py       ← เทรน LoRA (ต้องมี GPU)
│  ├─ 03_export_gguf.py ← แปลงโมเดลที่เทรนแล้วเป็น .gguf
│  ├─ 04_create_ollama.py ← สร้าง Modelfile + โหลดเข้า Ollama ในเครื่อง
│  ├─ pipeline.py       ← รันทุกขั้นตอนรวดเดียว (`python pipeline.py --step all`)
│  └─ run_test50.py     ← ทดสอบ 50 ข้อ ผ่าน backend ที่รันอยู่ในเครื่อง
├─ run.py              ← เปิดทุกอย่าง + ลิงก์ trycloudflare สำหรับมือถือ
├─ start.bat           ← ดับเบิลคลิกเพื่อเปิด (Windows)
└─ requirements.txt
```

**หมายเหตุสำคัญ**: โฟลเดอร์ `dataset/` และ `training/` เป็นเครื่องมือ "เตรียม/เทรนโมเดลใหม่" เท่านั้น ไม่ได้ถูกเรียกใช้ตอนแชทจริง
(ตอนแชทใช้แค่ `backend/rag_index.json` กับโมเดลที่สร้างเสร็จแล้วใน Ollama) — ใช้ตอนที่จะ **เทรนโมเดลรอบใหม่** เท่านั้น
ตอนนี้มี 2 ทางให้เทรน: **Colab** (`DSEE_Buddy_Colab.ipynb` — มี GPU ให้ใช้แน่นอน) หรือ **ในเครื่องเอง** ผ่านโฟลเดอร์ `training/`
(ต้องมีการ์ดจอ NVIDIA ที่แรงพอ ดูรายละเอียดและข้อจำกัดใน `training/README.md`) — ขั้นตอน/ผลลัพธ์เหมือนกันทั้งสองทาง
ต่างกันแค่รันที่ไหน

## ติดตั้งครั้งแรก

1. ต้องมีโมเดลใน Ollama แล้ว (ทำไปแล้ว):
   - `dsee-typhoon` ← โมเดลที่เทรนจากหลักสูตร (ตอบเรื่องหลักสูตร)
   - `hf.co/typhoon-ai/typhoon2.1-gemma3-4b-gguf:Q4_K_M` ← โมเดลทั่วไป (ตอบเรื่องอื่น/โค้ด/ไฟล์)
     ถ้ายังไม่มี: `ollama pull hf.co/typhoon-ai/typhoon2.1-gemma3-4b-gguf:Q4_K_M`
2. ติดตั้งไลบรารี Python:
   ```bat
   cd dsee_chat
   pip install -r requirements.txt
   ```
3. ติดตั้ง cloudflared (ใช้ทำลิงก์ให้มือถือเข้าได้จากทุกที่):
   ```bat
   winget install --id Cloudflare.cloudflared
   ```
   แล้วปิด-เปิด Command Prompt ใหม่ 1 ครั้ง

## เปิดใช้งาน

ดับเบิลคลิก `start.bat` หรือพิมพ์ `python run.py` หน้าจอจะแสดง

```
✅ DSEE Buddy พร้อมแล้ว!
   ในเครื่องนี้ :  http://localhost:8000
   🔑 PIN เข้าใช้งาน: 482913
📱 เปิดบนมือถือ: https://xxxx-xxxx.trycloudflare.com   (+ QR code ให้สแกน)
```

- เปิดลิงก์ trycloudflare บนมือถือ → ใส่ PIN ครั้งแรกครั้งเดียว → ใช้ได้เลย
- ลิงก์ใช้ได้จนกว่าจะปิดหน้าต่างนี้ เปิดใหม่จะได้ลิงก์ + PIN ใหม่
- คอมต้องเปิดไว้และต่ออินเทอร์เน็ตตลอดเวลาที่ใช้บนมือถือ
- ตัวเลือก: `python run.py --no-tunnel` (ใช้แค่ในเครื่อง/Wi-Fi เดียวกัน), `--no-pin` (ไม่ใช้ PIN — ไม่แนะนำ)

## ความเสถียร (ตั้งค่าไว้ให้แล้ว)
- เซิร์ฟเวอร์ส่งสัญญาณกันสายหลุดทุก 8 วินาทีระหว่างรอโมเดล → ไม่เจอ HTTP 524
- ตอบทีละคำถาม (คิว) กันโมเดลแย่งหน่วยความจำ / ปิดโมเดลที่อีกคนใช้อยู่
- Ollama หลุดกลางทาง ระบบลองใหม่ให้ 1 ครั้ง · หน้าเว็บก็ลองส่งใหม่ให้อัตโนมัติถ้าเจอ 502/530/เน็ตหลุด
- run.py กันคอมสลีป และเปิดเซิร์ฟเวอร์ใหม่เองถ้าล่ม (ลิงก์ + PIN เดิมใช้ต่อได้)

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| หัวเว็บขึ้น "ยังไม่ได้เปิด Ollama" | เปิดแอป Ollama ก่อน |
| `unable to allocate CPU buffer` | RAM ไม่พอ ปิดโปรแกรมอื่น / `ollama ps` แล้ว `ollama stop <ชื่อ>` โมเดลที่ไม่ใช้ |
| สลับระหว่างคำถามหลักสูตรกับเรื่องทั่วไปแล้วช้าครั้งแรก | ปกติ — Ollama กำลังสลับโหลดโมเดล (เครื่อง RAM น้อยโหลดได้ทีละตัว) |
| มือถือเปิดลิงก์ไม่ได้ | เช็กว่าหน้าต่าง run.py ยังเปิดอยู่ และใช้ลิงก์ล่าสุด |
| ลืม PIN / ใส่ผิด | ดูในหน้าต่าง run.py แล้วกด "แชทใหม่" หรือล้างข้อมูลเว็บในเบราว์เซอร์ |

ตั้งค่าเพิ่มเติมผ่าน environment variable: `DSEE_MODEL`, `GENERAL_MODEL`, `APP_PIN`, `PORT`, `OLLAMA_HOST`, `DB_PATH` (ไฟล์ฐานข้อมูลประวัติแชท ค่าเริ่มต้น `chat.db` ในโฟลเดอร์นี้), `DB_BACKUP_PATH` (ถ้าอยากสำรองไปไฟล์อื่น/โฟลเดอร์อื่น)

## ประวัติแชท

- ประวัติเก็บอัตโนมัติใน `backend/chat.db` (SQLite) แยกตามเครื่อง/เบราว์เซอร์ที่ใช้ — ไม่ต้องล็อกอิน
- กดปุ่ม ☰ มุมซ้ายบนของหน้าแชท เพื่อดู/สลับ/ลบบทสนทนาเก่า หรือเริ่มแชทใหม่
- ลบเบราว์เซอร์/ล้างข้อมูลเว็บ = ประวัติของเครื่องนั้นจะหาไม่เจออีก (เพราะระบุตัวตนด้วยรหัสที่เก็บในเบราว์เซอร์) ไฟล์ `chat.db` เองยังอยู่ในเครื่องเหมือนเดิม
